# FairShare 🏡💸

> Nền tảng quản lý chi tiêu chung và đối soát công nợ minh bạch dành cho người ở ghép (roommates) và nhóm bạn.

## 🚀 Tính năng nổi bật
- **Chia tiền linh hoạt:** Chia đều (Equal), Theo phần trăm (Percentage), hoặc Số tiền chính xác (Exact).
- **Tính toán số dư nợ gối đầu liên tục (Rolling Net Balance):** Tự động cập nhật công nợ sau mỗi lần chi tiêu hoặc thanh toán.
- **Tối giản hóa giao dịch (Debt Simplification):** Tự động gộp và tối ưu hoá số giao dịch cần chuyển khoản.
- **UI/UX chuẩn Pro Max:** Thiết kế hiện đại, Emerald Green + Zinc, Bento cards, hỗ trợ xem lịch sử và sao kê rõ ràng.

## 🛠️ Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Lucide React, Axios, React Router DOM
- **Backend:** Node.js, Express.js, Mongoose ORM
- **Database:** MongoDB
- **Authentication:** JWT + bcryptjs
